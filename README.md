# Iolite Index

Full-colour Python 3 neon letter-catch word arcade for ElbowOS.

Catch falling letters that match the next letter of the target word. Complete words for bonus score. Neon violet / cyan palette.

## Play

```bash
pip install -r requirements.txt
python3 iolite_index.py --play
```

A/D or left/right arrows to move the catcher. R to restart. Esc to quit.

## Record a 9:16 reel

```bash
python3 iolite_index.py --record
```

Outputs `IOLITE_INDEX_ElbowOS.mp4` (15s @ 30fps, 1080x1920).
